# Changelog

Все значимые изменения проекта.

версии — по [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] — 2026-10-15

Первый публичный релиз.

### Добавлено

- Распознавание японского текста через EasyOCR + manga-ocr
- Три переводчика на выбор: NLLB (локально), Google, Claude API
- Автоматическое стирание оригинала и вставка перевода
- Поддержка форматов webp, png, jpg, jpeg, bmp, tiff, gif
- Обработка отдельного файла или папки с главами
- Флаг `--gap` для настройки склейки соседних облачек
- Флаг `--no-merge` для работы с таблицами и словарями
- Флаг `--format` для конвертации результата
- Флаг `--font` для подключения своего шрифта
- Флаг `--gpu` для использования видеокарты

### Известные ограничения

- Звуковые эффекты на фоне стираются неидеально
- NLLB слабо переводит одиночные слова без контекста
- Google-переводчик легко ловит капчу при частых запросах
- Модель NLLB распространяется под CC-BY-NC-4.0 (некоммерческая)
