# Лицензии сторонних компонентов

Проект использует следующие библиотеки и модели. У каждой — своя лицензия,
отличная от MIT-лицензии самого скрипта.

| Компонент | Лицензия | Ссылка |
|---|---|---|
| EasyOCR | Apache-2.0 | https://github.com/JaidedAI/EasyOCR |
| manga-ocr | см. репозиторий | https://github.com/kha-white/manga-ocr |
| transformers | Apache-2.0 | https://github.com/huggingface/transformers |
| PyTorch | BSD-3-Clause | https://github.com/pytorch/pytorch |
| OpenCV | Apache-2.0 | https://github.com/opencv/opencv |
| Pillow | HPND | https://github.com/python-pillow/Pillow |
| deep-translator | MIT | https://github.com/nidhaloff/deep-translator |
| anthropic-sdk | MIT | https://github.com/anthropics/anthropic-sdk-python |
| facebook/nllb-200-distilled-600M | CC-BY-NC-4.0 | https://huggingface.co/facebook/nllb-200-distilled-600M |

## Важно
- NLLB распространяется под **CC-BY-NC-4.0** — некоммерческое использование.
- Google Translate через `deep-translator` — неофициальный доступ,
  использование может нарушать условия Google.
- Anthropic Claude — по условиям Anthropic.
